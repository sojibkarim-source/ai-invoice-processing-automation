# Portfolio publishing checklist

- [ ] Confirm workflow runs on a newly uploaded PDF.
- [ ] Complete each test in `docs/test_cases.csv` and record actual results.
- [ ] Capture screenshots of the workflow and both routing paths.
- [ ] Hide email addresses, IDs, credentials, tokens, and customer data.
- [ ] Use only synthetic invoices and spreadsheet rows.
- [ ] Add README and screenshots to a GitHub repository.
- [ ] Add a short demo video if possible.
- [ ] State limitations honestly: text-based PDFs only unless OCR is implemented.
- [ ] Do not publish credential exports or secrets inside workflow JSON.
